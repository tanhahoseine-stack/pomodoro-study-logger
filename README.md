# Pomodoro Study Logger — ثبت پومودورو مطالعه

پلاگین Obsidian برای ثبت پومودوروهای مطالعه در یادداشت روزانه؛ با انتخاب کتاب از «میز مطالعه»، پر شدن خودکار صفحه‌ی شروع، گزارش‌های روز/هفته/ماه/کل، زنجیره‌ی استمرار، نقشه‌ی گرمایی و کاپ.

> An Obsidian plugin (Persian UI, RTL) that logs study Pomodoros into your daily note: pick a book from your "study desk", the start page auto-fills, one click writes a checklist line and updates the daily frontmatter. Includes undo/delete of mistaken entries, day/week/month/total reports, habit streaks, a heatmap and a cup every 5 days of consistency.

## امکانات
- **میز مطالعه:** فقط کتاب‌هایی که «میز مطالعه» آن‌ها روشن است در فهرست نمایش داده می‌شوند؛ گروه‌بندی بر اساس «دسته‌بندی» (هر چه خودت بنویسی، مثلاً هفته اول)
- **برداشتن خودکار کتاب تمام‌شده:** وقتی صفحه‌ی پایان به انتهای محدوده‌ی کتاب برسد، میز مطالعه‌ی آن کتاب خاموش می‌شود
- **حذف ثبت اشتباه:** در بخش «آخرین ثبت‌ها» کنار هر ثبت دکمه‌ی حذف هست (با تأیید). خط از یادداشت پاک می‌شود، فراداده‌ی روزانه اصلاح می‌شود، صفحه‌ی شروع کتاب برمی‌گردد و اگر آن ثبت کتاب را تمام کرده بود، کتاب دوباره به میز مطالعه برمی‌گردد
- **گزارش‌ها:** تعداد پومودورو، زمان مطالعه و تعداد صفحه برای امروز، این هفته، این ماه و کل
- **استمرار:** زنجیره‌ی فعلی، رکورد استمرار، نقشه‌ی گرمایی (هفته‌های اخیر) و کاپ 🏆 به ازای هر ۵ روز پیاپی مطالعه (قابل تغییر)
- افزودن سریع کتاب با «➕ افزودن کتاب»
- صفحه‌ی شروع خودکار؛ پایان − شروع = تعداد صفحات
- ثبت چک‌لیست در یادداشت روزانه‌ی امروز و به‌روزرسانی `پومودورو`، `صفحات_خوانده`، `مطالعه_دقیقه`
- نوار پیشرفت روزانه، ورودی اعداد فارسی/عربی، تقویم شمسی
- حالت‌های نمایش: مودال، سایدبار، Code Block
- سازگار با موبایل و دسکتاپ؛ بدون تله‌متری و بدون درخواست شبکه

## نصب

### از Release (بعد از انتشار در گیت‌هاب)
از صفحه‌ی Releases فایل‌های `main.js`، `manifest.json` و `styles.css` را دانلود کن و در این مسیر بگذار:

```
<vault>/.obsidian/plugins/pomodoro-study-logger/
```

سپس در Settings ← Community plugins پلاگین را فعال کن. (با افزونه‌ی BRAT هم می‌توان مستقیم از آدرس مخزن نصب کرد.)

### از سورس
```
npm install
npm run build
```
سه فایل بالا را مثل بخش قبل کپی کن.

## استفاده
- آیکون ⏱ در نوار کناری یا دستور «باز کردن ثبت پومودورو» (حالت پیش‌فرض در تنظیمات)
- فرم سه تب دارد: **ثبت**، **گزارش‌ها**، **استمرار**
- در یادداشت‌ها:

````
```pomodoro-logger
```
````

برای نمایش فقط یک بخش (مثلاً گزارش یا نقشه‌ی گرمایی در داشبورد خودت) داخل بلوک بنویس:

````
```pomodoro-logger
tab: streak
```
````
مقدار `tab` می‌تواند `log`، `stats` یا `streak` باشد.

## یادداشت کتاب
```yaml
---
type: کتاب
میز_مطالعه: true
ص_ابتدا: 1
ص_انتها: 300
دسته_بندی: هفته اول
---
```
نام همه‌ی این فیلدها در تنظیمات قابل تغییر است. اگر کتاب‌های قدیمی با فیلدهای `فعال` و `هفته` داری، در تنظیمات دکمه‌ی «انتقال کتاب‌های قدیمی» آن‌ها را به `میز_مطالعه` و `دسته_بندی` تبدیل می‌کند.

## زنجیره و کاپ
روزی در زنجیره حساب می‌شود که حداقل N پومودورو (پیش‌فرض ۱) ثبت شده باشد. تا پایان امروز زنجیره نمی‌شکند. هر ۵ روز پیاپی یک کاپ می‌گیری (مثلاً زنجیره‌ی ۱۲ روزه = ۲ کاپ) و در لحظه‌ی رسیدن به کاپ یا رکورد جدید، پیام تشویقی نمایش داده می‌شود.

## قالب خط پومودورو
پیش‌فرض: `- [x] 🍅{{index}} [کتاب:: {{book}}] [از:: {{from}}] [تا:: {{to}}]`
جایگزین‌ها: `{{index}}`، `{{book}}`، `{{from}}`، `{{to}}`. نام برچسب فیلدها و نشانگر (🍅) از خود قالب خوانده می‌شود؛ اگر یادداشت الگو خطی با همین قالب و مقدارهای خالی داشته باشد، اول آن پر می‌شود.

## توکن‌های مسیر
`{{date}}` (YYYY-MM-DD)، `{{jyear}}` (سال شمسی)، `{{year}}`، `{{month}}`، `{{day}}`

## توسعه
```
npm install
npm run dev      # ساخت و دیدن تغییرات (watch)
npm run build    # بررسی تایپ + ساخت نهایی
```
ساختار: `main.ts` (ورودی)، `src/` (منطق و آمار)، `src/ui/` (فرم، گزارش‌ها، مودال، سایدبار).

## انتشار نسخه‌ی جدید
1. `npm version patch` (یا minor / major) ← `manifest.json` و `versions.json` هم به‌روز می‌شوند.
2. `git push && git push --tags`
3. GitHub Actions یک Release پیش‌نویس با `main.js`، `manifest.json` و `styles.css` می‌سازد؛ آن را Publish کن.

## حریم خصوصی
بدون تله‌متری، بدون درخواست شبکه، بدون `eval`؛ همه‌چیز محلی در Vault انجام می‌شود.
